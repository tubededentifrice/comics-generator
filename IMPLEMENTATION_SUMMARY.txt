   $ cd /Volumes/External/git/comics-generator

================================================================================
                       PACKAGING FOR DISTRIBUTION
================================================================================

OPTION 1: Mac App Store (Recommended for wide reach)
   Requirements: Apple Developer Account ($99/year)
   Steps:
   1. Product → Archive in Xcode
   2. Organizer → Distribute App → App Store Connect
   3. Upload to App Store Connect
   4. Configure metadata, screenshots, pricing
   5. Submit for review (1-3 days)
   Benefits: Automatic updates, wide reach, trusted source

OPTION 2: Direct Distribution (DMG)
   Requirements: Developer ID certificate ($99/year)
   Steps:
   1. Product → Archive in Xcode
   2. Organizer → Distribute App → Developer ID → Export
   3. Create DMG: hdiutil create -volname "Comics Generator" \
                      -srcfolder "ComicsGenerator.app" \
                      -format UDZO "ComicsGenerator.dmg"
   4. Notarize with Apple (xcrun notarytool)
   5. Distribute via website or download link
   Benefits: No review process, full control, faster updates

OPTION 3: iOS App Store (iPad)
   Same as Mac App Store but with iPad-specific:
   • iPad screenshots (required sizes)
   • Touch-optimized testing
   • Apple Pencil support verification

OPTION 4: Open Source (GitHub)
   Steps:
   1. git tag v1.0.0
   2. Create GitHub Release
   3. Attach DMG or provide build instructions
   Benefits: Free, community-driven, transparent
